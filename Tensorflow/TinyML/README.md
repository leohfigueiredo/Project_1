# TinyML - Tiny Machine Learning

This folder contains notebooks focused on TinyML (Tiny Machine Learning) concepts, which involve running machine learning models on resource-constrained devices like microcontrollers and embedded systems.

## 📁 Notebooks

### Exploring_Loss_Cost_Function.ipynb

This notebook explores loss functions (also known as cost functions) in machine learning:
- Understanding what loss functions are and their importance
- Visualizing loss functions with simple linear regression examples
- How loss functions guide model optimization
- Practical examples with input/output data pairs
- Graphical representation of loss calculations

**Key Concepts Covered:**
- Mean Squared Error (MSE)
- Loss calculation
- Model optimization through loss minimization

---

### IESTI01_data_augmentation.ipynb

This notebook covers data augmentation techniques, which are essential for improving model generalization, especially when working with limited datasets:
- What is data augmentation and why it's important
- Image data augmentation techniques (rotation, flipping, zooming, etc.)
- Using TensorFlow's ImageDataGenerator for augmentation
- Practical examples with image datasets
- How augmentation helps prevent overfitting

**Key Concepts Covered:**
- Data augmentation strategies
- Image transformations
- Overfitting prevention
- Dataset expansion techniques

---

## 📝 Requirements

To run these notebooks, you will need:
- Python 3.7+
- TensorFlow 2.x
- Jupyter Notebook/JupyterLab
- Additional libraries: numpy, matplotlib, scikit-learn

## 🚀 How to Use

1. Navigate to this folder
2. Open any notebook in Jupyter: `jupyter notebook notebook_name.ipynb`
3. Run the cells sequentially to follow along with the examples
